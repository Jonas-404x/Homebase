# Mainframe brand assets

The Mainframe logo: a rounded black app icon with a white `>m` prompt and an ice-blue cursor. Raster files only (no SVG), with transparent corners.

| File | Size | Used for |
| --- | --- | --- |
| `app.ico` | 16–256 px | Windows icon (taskbar, desktop shortcut, future installer/`.exe`) |
| `favicon.ico` | 16, 32, 48 px | Browser tab |
| `favicon-32.png` | 32 px | Browser tab (PNG) |
| `apple-touch-icon.png` | 180 px | iPhone/iPad home screen |
| `icon-192.png` | 192 px | Web app icon (PWA, Android) |
| `logo-512.png` | 512 px | README, PWA, general use |
| `logo-1024.png` | 1024 px | Large uses, GitHub social preview |
| `logo-original.png` | 1254 px | Source image |

The web UI serves copies from `apps/web/public/`.
